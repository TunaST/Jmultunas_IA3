IT Portfolio Development Plan

Project Goal

Create a personal IT portfolio website that showcases my professional background, certifications, technical skills, and leadership experience.

Initial Approach

I wanted to start with a basic professional website and improve it as I reviewed the results.

Rather than designing every feature upfront, I planned to use AI to help generate the initial website and then make adjustments based on what I liked or wanted changed.

Development Steps

1. Build the Initial Website

Start with a homepage introducing my IT background and experience.

Include sections for:

Professional introduction

Technical skills

Certifications

Leadership experience

Projects and accomplishments

Contact information

2. Improve the Design

Review the initial website and request changes to the layout, colors, images, and formatting.

Make sure the website looks professional and works on different screen sizes.

3. Add Portfolio Information

Include relevant experience in infrastructure, networking, cybersecurity, and IT management.

Use my actual certifications and professional experience.

4. Test the Website

Run the application locally and check that the pages, images, and navigation work correctly.

Address any problems discovered during testing.

5. Deploy the Website

Use Google Cloud Run to host the portfolio.

Work through the deployment process and troubleshoot any issues that prevent the website from working correctly.

6. Upload to GitHub

Create a GitHub repository containing the source code and supporting project documentation.

7. Final Review

Open the live website, verify that the content and images display correctly, and prepare the assignment submission.
