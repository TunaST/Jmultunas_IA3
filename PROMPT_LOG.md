# AI Prompt Log

This document summarizes the main requests and follow-up questions used during development of my IT portfolio. The prompts are paraphrased to describe the development process rather than reproduced as exact transcripts.

## Prompt 1 — Initial Website
**Request:** Help me create a professional IT portfolio website that highlights my background in networking, infrastructure, cybersecurity, and leadership.

**Goal:** Create the starting version of the website.

## Prompt 2 — Website Design
**Request:** Make the website look more modern and professional. I want something that would look good when applying for IT management positions.

**Goal:** Improve the appearance and layout.

## Prompt 3 — Professional Experience
**Request:** Add sections for my work experience, technical skills, certifications, and leadership background.

**Goal:** Make the portfolio reflect my professional experience.

## Prompt 4 — Certifications and Images
**Request:** Add images for my CCNP Enterprise, PCNSE, and IT leadership sections.

**Goal:** Improve the visual presentation of the portfolio.

## Prompt 5 — Image Formatting
**Request:** Make the project images consistent in size so they look better on the website.

**Goal:** Improve image sizing and alignment.

## Prompt 6 — Running the Website
**Request:** Help me run the website locally and make sure everything is working.

**Goal:** Test the application before deployment.

## Prompt 7 — Google Cloud Deployment
**Request:** Walk me through deploying my website to Google Cloud Run.

**Goal:** Make the website publicly accessible.

## Prompt 8 — Deployment Troubleshooting
**Request:** Help me troubleshoot the errors I'm getting when deploying the website.

**Goal:** Resolve Google Cloud build and permission problems.

## Prompt 9 — Missing Images
**Request:** The website is deployed, but the images aren't showing. How can I fix this?

**Goal:** Correct the Docker configuration so the images are included in the deployed application.

## Prompt 10 — GitHub Repository
**Request:** Help me upload the completed project to GitHub.

**Goal:** Store the source code and documentation in a repository.

## Prompt 11 — GitHub Authentication
**Request:** I'm getting authentication and permission errors when pushing to GitHub. How do I fix them?

**Goal:** Resolve token permissions and successfully upload the project.

## Final Outcome
The website was successfully deployed to Google Cloud Run, the missing images were fixed, and the source code was uploaded to GitHub.

The AI assistance was most useful for generating the initial application, making design changes, explaining technical issues, and troubleshooting deployment problems.
